# Glosarium (ID ↔ EN)

Istilah tetap yang dipakai di tampilan aplikasi, pesan CLI, dan dokumentasi. Satu konsep, satu istilah. Sapaan: **Anda** (bukan "kamu"). Sebut yang menjalankan tugas sebagai **asisten**.

## Mode izin

| Indonesia | English | Catatan |
|---|---|---|
| Tanya dulu | Ask first | Mode bawaan. Selalu bertanya sebelum mengubah, menjalankan perintah, atau membuka web. |
| Edit otomatis | Auto edit | Mengubah file di proyek tanpa bertanya. Perintah tetap bertanya. |
| Rencana | Plan | Hanya membaca dan menyusun rencana. Di kalimat: "mode Rencana". |
| Otomatis-aman | Safe auto | Seperti Edit otomatis, ditambah perintah yang selalu diizinkan. |
| Penuh | Full | Tanpa bertanya. Hanya untuk folder yang benar-benar dipercaya. |
| folder dipercaya / belum dipercaya | trusted / untrusted folder | Diatur dengan `ezkielyna trust`. Jangan pakai "tepercaya". |
