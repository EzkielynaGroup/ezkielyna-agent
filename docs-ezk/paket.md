# Paket dan model

Model yang bisa Anda pakai bergantung pada **jenis kunci**. Daftar lengkap dan harga terbaru ada di:

- Model dan harga: https://ezkielyna.store/models
- Status layanan: https://ezkielyna.store/status

Aplikasi membaca daftar model dari kunci Anda sendiri, jadi yang muncul di daftar adalah yang benar-benar boleh dipakai.

| Kunci | Isi |
|---|---|
| **Standard** | Model harian dari keluarga DeepSeek, GLM, Kimi, MiniMax, Qwen, MiMo. Ada alias **Auto** (pilih otomatis). Tanpa Claude/GPT. |
| **Premium** | Semua di Standard, ditambah model kelas atas seperti Claude, GPT, Grok, Gemini. Harga lebih tinggi (sekitar 1,5x). Ketersediaan tiap model bisa berubah, cek halaman model. |
| **Flash** | Model cepat dan hemat untuk tugas harian: `deepseek-v4.1-flash`, `minimax-m3.1-flash` (dan varian Flash lain). Kuota mengikuti paket yang Anda beli. |
| **Luna** | Paket khusus keluarga model GPT "Luna". Tersedia dalam beberapa ukuran kuota. |

Catatan:
- **Auto (Pintar)** hanya memakai model yang ada di kunci Anda. Kunci Flash tetap di model Flash.
- Daftar di atas adalah gambaran umum. Yang berlaku untuk Anda adalah yang tampil di aplikasi dan di https://ezkielyna.store/models.
- Jika sebuah model sedang bermasalah, lihat halaman status.
